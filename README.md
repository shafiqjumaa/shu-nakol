# شو ناكل؟ — تطبيق طلبات الطعام للشركة

واجهة عربية RTL ومتجاوبة للهواتف، تتيح للموظفين إرسال طلبات الطعام اليومية، وللمسؤول متابعة الطلبات وإضافة الأسعار وتصدير CSV.

## تشغيل محلي
1. ثبّت Node.js LTS.
2. نفّذ `npm install` ثم `npm run dev`.
3. من دون إعداد Supabase يعمل التطبيق في وضع معاينة محلي ببيانات تجريبية غير دائمة.

## ربط قاعدة البيانات
- أنشئ مشروع Supabase.
- نفّذ ملف `supabase/schema.sql` في SQL Editor.
- انسخ `.env.example` إلى `.env` وأدخل `VITE_SUPABASE_URL` و`VITE_SUPABASE_ANON_KEY`.
- أنشئ حساب المسؤول من لوحة Supabase Authentication.

## النشر
إعدادات البناء: `npm run build` ومجلد الناتج `dist`.

## تنبيه أمني مهم
ملف SQL الحالي نقطة بداية للتجربة وليس إعداداً جاهزاً للإطلاق العام. قبل مشاركة الرابط يجب تقييد صلاحيات الإدارة بدور admin حقيقي، وإضافة تحقق من الطلبات ومعدل الإرسال، وعدم كشف بيانات طلبات الموظفين للعامة. لا تضع service-role key في الواجهة الأمامية.
